# SEMDS-HW3
Homework #3 — User Stories for Final Project

### Assignment

Create a `UserStory.md` file in your **final project** repository that contains **20 user stories** describing how different users would interact with your software. As a reminder, each user story should clearly address who is the user,
what they want to do with the tool, what needs or desires they want for the tool, and what is their skill level. Multiple stories can be written about similar users, as long as each story represents a distinct and realistic situation. 1 pt  for each item.

1. Clone the project repository to your local computer.
2. Create a `UserStory.md` file in the repository.
3. Add 20 user stories to this file.
4. Add the file to the staging area, commit, and push changes to GitHub.
5. Tag the TA in a GitHub issue to review.
