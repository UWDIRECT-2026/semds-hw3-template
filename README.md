# SEMDS-HW3
Homework #3 — User Stories and Project Components

### Assignment

Create a `UserStory.md` file in your **final project** repository that contains at least **20 user stories** describing how different users would interact with your software. Create a `Components.md` file in your **final project** repository that contains at least **5 components** describing how the code will be structured and implemented for the project. As a reminder, each user story should clearly address who the user is,
what they want to do with the tool, what needs they have for the tool, and their skill level. Multiple stories may describe similar types of users, but each story must represent a distinct and realistic situation. Each component description must include the component name, what it does, its inputs/outputs (with type information), and how it interacts with other components. 1 pt  for each item.

1. Clone the project repository to your local computer.
2. Create a `UserStory.md` and `Components.md` file in the repository.
4. Add at least 20 user stories and 5 components to the respective files.
5. Add the file to the staging area, commit, and push changes to GitHub.
6. Tag the TA in a GitHub issue to review.
